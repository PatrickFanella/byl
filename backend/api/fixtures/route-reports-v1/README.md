# Route report API fixtures, version 1

These synthetic requests and response reference revision 1 in the neighboring
`tour-revisions-v1` fixtures. They describe no real obstruction, visit or reviewed
alternative. They contain no credentials or background location history.

`minimal-request.json` reports a blocked entrance with no source, date or alternate
path. The normalized `report-response.json` makes unknown direction/duration and
missing optional values explicit. `alternative-request.json` suggests a local
segment improvement and says what would improve. Its geometry is an unverified
proposal, not evidence of legal access.

Web, iOS and Android can use these shapes for their later report forms. Current
clients are unchanged. Reports and their dispositions are private to their
submitter and curators; acceptance never edits a route or publishes history.
