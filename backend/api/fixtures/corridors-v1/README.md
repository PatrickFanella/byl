# Corridor intent fixtures, version 1

`intent.json` is a synthetic Prairie Path branch/topology exercise that references
story-stop IDs in the neighboring tour revision fixture. Its coordinates, graph,
mode permissions and example.org source records are test data, not an imported
real trail map or evidence of public access. No remote retrieval is performed.

The main segment explicitly supports Elgin and Aurora choices. The selected path
uses Elgin; the adjacent road and separated crossing have different node IDs.
The road connector requires explicit selection and its own source context. The
shaping point belongs to a path occurrence between two stable story stops and
never creates an exhibit or arrival event. Tests exercise alternate branches,
connectors and changed references with this same bounded input.
